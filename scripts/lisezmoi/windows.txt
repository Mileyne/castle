Castle v@VERSION@ - Windows 64 bits

Lancer : castle_client.exe   (castle_server.exe doit rester a cote: le jeu le lance tout seul)
Menu : Jouer en solo / Cooperatif: heberger / Cooperatif: rejoindre (adresse IP de l'hote, reseau local)
Echap en jeu : pause, ou abandonner le niveau et revenir au menu
Parties sauvegardees (a chaque entree de niveau) : %APPDATA%\Castle\saves

Cooperatif : autoriser castle_server.exe dans le pare-feu Windows (UDP 5000).
Premier lancement : SmartScreen peut afficher un avertissement (programme non signe): "Informations complementaires" puis "Executer quand meme".
